Installation

Windows: Download .exe or .msi and run the installer.

Linux: On Debian/Ubuntu use sudo dpkg -i consume-halal.deb or install the .AppImage as a portable binary.

macOS: Open the .dmg, drag ConsumeHalal to Applications. Allow the app on first launch via System Settings → Privacy & Security.

Android: Download the .apk and install directly — allow "Install unknown apps" for your browser if prompted.

iOS: Join the TestFlight build via the link in the Downloads section.

Features

Daily Guides: A structured path that assigns a daily recitation module. Each module is a set of verses with context and translation, designed to build consistency over time.

Live Audio Feedback: The app listens to your recitation in real time and flags tajweed issues — improper elongation, missing stops, or incorrect vowel points. Feedback is local and private.

Practical Guides: Actionable study material that explains the "why" behind each rule so you can apply it beyond the app.

FAQ

Is ConsumeHalal free?
Yes. ConsumeHalal is 100% free and open-source under the MIT license. No ads, no subscriptions, no data collection.
Is my recitation data stored?
No. All audio processing happens on-device. Nothing is uploaded to a server.
Which platforms are supported?
Windows, Linux (Debian/Ubuntu), macOS, Android, and iOS (via TestFlight).
How do I verify a download?
Each GitHub release includes a checksums.txt. Run sha256sum -c checksums.txt after downloading to verify integrity.
Can I contribute?
Yes. The source is at github.com/mahir-sys/consume-halal. Open an issue or submit a pull request.
