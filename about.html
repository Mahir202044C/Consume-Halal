What is ConsumeHalal?

ConsumeHalal is a free, open-source Islamic recitation and study companion. It combines structured daily guides with real-time audio feedback and practical teaching material, built as a cross-platform desktop and mobile application.

Tech Stack

The app is built with Tauri and Rust. The Tauri runtime keeps the app lightweight across Windows, Linux, macOS, Android, and iOS without bloating with a web engine. All recitation logic, audio processing, and data storage are handled in native Rust.

Contribute

Bugs, feature ideas, and pull requests are welcome at github.com/mahir-sys/consume-halal. The best place to start is the issues page — look for the good first issue label.

Privacy

There is no analytics, no telemetry, and no network calls in the core app. Your recitation stays on your device.
